## 1. Запуск проекта с использованием Docker Compose

В корневой директории проекта выполните следующую команду для сборки и запуска всех контейнеров:

```bash
docker-compose up --build
## 2. Доступ к сервисам

После успешного запуска контейнеров сервисы будут доступны по следующим адресам:

- **Frontend (React)** — http://localhost:3000  
- **Keycloak (Authentication)** — http://localhost:8080  
- **Reports API (Backend)** — http://localhost:8000  
- **Airflow (ETL)** — http://localhost:8081  

---

## 3. Вход в Keycloak

Для тестирования авторизации и получения токена выполните следующие шаги:

1. Перейдите в Keycloak по адресу:  
   http://localhost:8080
2. Войдите, используя учетные данные администратора:
   - **Логин:** `admin`
   - **Пароль:** `admin`

---

## 4. Проверка функционала

1. Перейдите на Frontend по адресу:  
   http://localhost:3000
2. Выполните вход через Keycloak, используя предоставленные учетные данные.
3. На странице отчётов нажмите кнопку **Download Report**.
4. Убедитесь, что:
   - отчет успешно загружается;
   - данные пользователя подгружаются корректно.

---

## 5. Проверка работы Airflow

1. Перейдите в интерфейс Airflow по адресу:  
   http://localhost:8081
2. Убедитесь, что DAG (ETL-процесс):
   - отображается в списке DAG’ов;
   - успешно выполняется без ошибок.
3. Проверьте, что данные из CRM и телеметрии загружаются в OLAP-базу.

---

## 6. Остановка контейнеров

После завершения работы остановите и удалите контейнеры командой:

```bash
docker-compose down
